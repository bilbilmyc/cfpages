# 多文档工作台变更范围

2026-09-19，实施前已核对下列依赖与测试。沿用单站主管理密钥、现有设计变量和 Pages/D1 架构；本轮集中完成文件管理。

## 修改与新增

| 入口 | 作用 | 变更 |
| --- | --- | --- |
| `migrations/0004_tool_documents.sql` | 新文件表 | 独立 ID、类型、名称、版本、归档和最近打开时间；增量建表 |
| `server/api/documents.ts` | 受保护的文件 API | 列表、创建、读写、重命名、复制、归档恢复、打开、旧草稿导入 |
| `src/lib/toolDocumentData.ts` | 纯数据约束 | 流程图和画布校验由前后端共享 |
| `src/components/documents/` | 文件库与编辑外壳 | 内存会话、首页文件列表、自动保存、冲突及恢复副本 |
| `src/pages/Home.tsx`、`src/App.tsx` | 首页和路由 | 文件库位于首页，文件独立 URL |
| `src/pages/Flow.tsx`、`Canvas.tsx` | 已有编辑器 | 可嵌入文件编辑外壳，保留免登录本地草稿与兼容旧云草稿入口 |
| `src/lib/cloudDraft.ts` | 旧同步 | 文件模式禁用旧单草稿同步，避免串写 |

## 依赖与参考

- `server/http.ts` 继续负责鉴权、同源校验、流式请求大小限制；新路由挂到现有 Hono `/api/admin` 边界。
- `server/api/admin-posts.ts` 的版本号条件更新作为并发参考，任何文件内容或名称变更都必须 CAS；打开记录不递增内容版本。
- `src/lib/posts.ts` 复用 JSON 请求；会话密钥不写入 localStorage/sessionStorage。
- `tokens.css`、`design.md`、现有 `.button` 样式保持紧凑中文界面。
- `scripts/local.mjs`、Playwright 和 CI 使用独立本地 D1/R2；云端先预览后生产。

## 测试与风险审阅

- 新 API 测试覆盖权限、数据类型、长度、CRUD、分页、复制独立性、归档写入拒绝、并发冲突、幂等旧草稿导入。
- 浏览器测试覆盖完整文件生命周期、跨会话重新打开、慢保存串行化、失败/冲突恢复、切换文件不会串写，以及窄屏布局。
- 需要增量迁移；不删除旧 `tool_drafts`，导入是一次性副本，重复连接不覆盖已经编辑的新文件。
- 云文件内容不公开；未登录只可用本地工具。首页连接文件库后展示自己的文件，刷新重新连接。
- 文件恢复副本按 ID 隔离，遇到版本冲突暂停保存并支持另存副本；不静默覆盖另一设备内容。
- 既有草稿 API 和文章/图片地址保持兼容；无需改生产绑定。

审阅结论：这些边界能保留原有数据和访客工具；实现后必须通过独立环境的数据库、浏览器和并发测试，再执行预览与生产迁移。
