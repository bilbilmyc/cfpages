## 迁移与兼容

`0004_tool_documents.sql` 仅新增 `tool_documents` 表和最近打开索引。预览先执行，真实接口验收通过后再在生产执行；不修改 `images`、`posts`、`tool_drafts`。

首次连接文件库通过受保护接口复制两种旧云草稿，固定导入 ID 并使用 `ON CONFLICT DO NOTHING`，不会覆盖已编辑文件。格式不兼容时跳过并提示，旧草稿保留。后续旧草稿与新文件独立保存。

控制台手动执行 SQL 不会注册 Wrangler 迁移账本；两者要分别核查。新的本地预览会按文件顺序执行全部迁移。
